SCIENTIFIC BACKGROUND

How to interpret the simulator

Research question & data

How do rainfall occurrence patterns and intensity influence the probability of extreme rainfall events in Colombo? The model uses Open-Meteo Best Match hourly precipitation (2001–2025), reconstructed into daily totals. Calibration uses 2001–2020; historical evaluation uses 2021–2025. Data are CC BY 4.0; the underlying model composition and acquisition provenance are uncertain.

Occurrence and intensity

A two-state Markov chain draws wet/dry occurrence from the preceding state. Wet amounts use a Gamma distribution conditioned on rainfall ≥ 0.1 mm, sampled by rejection rather than clipping. Seasonal models select parameters by destination date (NEM Dec–Feb, FIM Mar–Apr, SWM May–Sep, SIM Oct–Nov), retaining the previous state across boundaries.

Using the dashboard

Choose a model, calendar, duration, scenario and seed. Start animates the trajectory; Pause and Resume preserve state; Run instantly completes the remaining days. Reset clears results and unlocks controls. The same configuration and seed reproduce a trajectory in this JavaScript implementation. Longest spells include observed partial endpoint runs.

Extreme-event interpretation

P95 and P99 are fixed all-day calibration thresholds; an event must strictly exceed the threshold. Marginal risk = wet probability × conditional tail probability. Within the investigated ±20% range, conditional intensity has the strongest influence on marginal risk; persistence affects clustering. Analytical risk averages time-dependent model probabilities, not uncertainty intervals for a single trajectory.

Scientific limitations

This is not an operational weather forecast. Rainfall exceedance probability is not flood probability. Scenario perturbations are not climate projections or causal interventions. Historical reanalysis and hourly/daily aggregation conventions carry uncertainty; Gamma underestimates some historical upper-tail rainfall and first-order occurrence misses exceptionally long spells. Seasonal modelling improves climatology, not every extreme statistic.

Verification

The Python notebook is the scientific source of truth. The browser uses its generated parameter asset, a seeded JavaScript generator and independent analytical comparisons. JavaScript and NumPy random streams are different; compare distributions and expectations, not individual sequences.
